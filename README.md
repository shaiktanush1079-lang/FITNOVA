
# ⚽ SPORTS ZONE
### Your Game. Your Gear.

SPORTS ZONE is a sports accessories e-commerce website where users can explore, search, and shop for accessories from different sports categories at affordable prices.

The application provides user registration, login, product searching, category filtering, shopping cart management, and a checkout demonstration.

---

## 📌 Project Overview

SPORTS ZONE is designed to provide a convenient online shopping experience for sports enthusiasts.

Users can browse sports products, view product information, add products to their shopping cart, manage quantities, and place demo orders.

## 🚀 Installation and Setup

### Step 1: Download the Project

Download or clone the project to your computer.

### Step 2: Open the Project

Open the SPORTS-ZONE folder using Visual Studio Code.

### Step 3: Install Live Server

1. Open VS Code.
2. Go to Extensions.
3. Search for Live Server.
4. Install the extension.

### Step 4: Run the Application

1. Open index.html.
2. Right-click inside the editor.
3. Select Open with Live Server.
4. The website will open in your browser.

1. Open the SPORTS ZONE website.
2. Create an account using your name, email and password.

## 🔒 Data Storage and Security

The current prototype uses browser Local Storage to maintain demonstration data.

**Important limitations:**
- Authentication is not production-secure.
- Passwords are stored in browser storage.
- Cart and order records are stored locally.
- Data is not synchronized between different devices.
- Online payments are not actually processed.

For production deployment, integrate secure authentication, a backend database, server-side validation and a legitimate payment gateway.
